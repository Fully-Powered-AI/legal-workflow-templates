# Sources and credits

Written by Fully Powered AI in its own words. The main ideas come from the open-source review method in anthropics/claude-for-legal (Apache-2.0): settle how the software reaches people before listing any duty; compare the licence a package declares with what its own files say, including a source file header that disagrees with the licence file; never treat a licence that cannot be pinned down as free of conditions; watch for a package offered under a choice of licences and for a licence text from another version; take the company's own open-source policy as the authority; and leave contested readings of a licence to a lawyer. No text from it is reused. Fully Powered AI left out that method's licence families, risk ratings, recommendations and view on whether code can ship, and added the rule that only the policy's own categories and words are used, a quoted line with file and line number for every licence found, the numbered review reasons as one fixed list, the row-for-row count against the dependency list, the checks on the policy's dates and approval, and the draft addressed to counsel with a line for each decision. No licence information or policy comes with the workflow template.
