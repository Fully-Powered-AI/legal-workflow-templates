# Sources and credits

Written by Fully Powered AI in its own words. The starting idea comes from the amendment history instructions in the commercial contracts package published in anthropics/claude-for-legal (Apache-2.0): set a base agreement and its amendments in date order, using the dates each amendment gives for the earlier papers as a cross-check; ask which provision is meant when a name fits more than one; follow that provision through each document that changes it, giving the exact words and the section they sit in; pass over documents that leave it alone; and call out oddities: a party added or renamed with no transfer on file, a section that moved number, a change aimed at a provision already removed, contradictory language between amendments, and two documents that appear to be the same amendment. That package also leaves a conflict between documents to the lawyer, drafts no amendment and compares nothing with a playbook, and this workflow template keeps all three limits. The rest is written as Fully Powered AI's own rules for this workflow template: compare the orders by latest signature date, number and stated effective date; report each signature block and any draft marking as separate facts, and leave whether and when a document was executed to the lawyer; list a version with a blank signature block or a draft marking only by its title, marking, number, stated date and signature blocks and quote none of its wording; set letters, emails and notices aside under a sorting rule counsel can change, with a gap for the lawyer; check the company's own contract register under fixed column headers; write no combined text from changes made in place; search for the number and heading of the section that holds the provision and for words that apply across the agreement as well as for the provision itself, and report each search as words found or not found, never as an effect; list the places that name or redefine the defined terms the provision uses; number the gaps in a fixed order of types; prepare nothing until a lawyer is named, outside counsel included; and give that lawyer a line-by-line list to confirm. Unlike the package, it never states the current controlling language at all, and it never passes over a document as leaving the provision alone: a document where the search finds nothing is listed, and the lawyer is asked about it. No third-party text is reused.
