# Sources and credits

Written by Fully Powered AI in its own words. One published method informed it: the instructions for handling an incoming demand in anthropics/claude-for-legal (Apache-2.0). From that method came three ideas: reading the same set of points from every letter that arrives, including how and when it arrived and any marking on it; looking through the company's own past and current matters for the same party before anything else happens; and leaving the law a letter cites for the lawyer to verify rather than checking it. Its list of first steps also raises holding on to records, which Fully Powered AI turned into a question for counsel. Fully Powered AI left out that method's merit rating, response options, recommendation, deadline work and hand-offs, and added its own rules: every date copied and never counted, every record named in the letter's own words, matching only on names and reference numbers, the company's records map with its deletion rules set beside that question, the list of documents to gather, and the record addressed to a named lawyer. No third-party text is reused.
